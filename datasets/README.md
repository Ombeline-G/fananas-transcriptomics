# Jeux de données actifs

Un dossier par étude, nommé selon `auteur_année_plateforme`. Seuls les datasets actifs sont conservés ici.

| Dossier | Usage courant |
|---|---|
| `zhang_zhuang_2023_merfish/` | Dataset spatial principal MERFISH |
| `hao_2024_stereo_seq/` | Dataset spatial principal Stereo-seq |
| `suyama_2026_xenium/` | Dataset spatial principal Xenium adulte |
| `siletti_2023_snrna/` | Validation atlas humain |
| `kozareva_2021_snrna/` | Provenance de l’atlas murin utilisé dans Hao |

Les résultats combinés ne vivent jamais dans ces dossiers : ils sont exclusivement dans
`../comparison/`.
